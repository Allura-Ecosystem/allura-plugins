# Allura Plugins

Canonical, organization-owned plugin catalog for the Allura ecosystem.

This repository aligns Allura capabilities across Claude and Codex while
preserving runtime-specific manifests and integration mechanisms. Home
directories are installation and cache surfaces, not authoring authorities.

## Status

The catalog is in inventory and validation. No desktop runtime should install
from this repository until the approved packages pass both runtime validation
gates.
