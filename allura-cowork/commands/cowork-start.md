# cowork-start

Start a governed Claude/Codex cowork session.

## Steps

1. State the active runtime.
2. Inspect the project for `AGENTS.md`, `.claude/`, `.codex/`, `.opencode/`,
   `.agents/`, and local plugin/skill files.
3. Search Allura Brain with `group_id=allura-system` for relevant decisions,
   blockers, preferences, and prior work.
4. Identify project overlay: Team RAM, Durham, TALON, IRIS, or none.
5. Apply `docs/ADAPTIVE-WORK.md`: select quick/standard/sensitive, route one owner
   and the reviewer required by risk. Reuse a fresh scoped packet on continuation;
   refresh only changed inputs. Do not ask again for already granted authority.
6. Name validation evidence before work starts.

## Output

Use the required Cowork Header from the `allura-cowork` skill.
