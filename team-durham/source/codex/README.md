# Team Durham For Codex

This is the Codex-facing adapter for Brand Maker.

Start here:

1. Read `AGENTS.md` in this directory for agent routing.
2. Use `skills/README.md` to map requested work to Team Durham skills.
3. Use `commands/README.md` to find canonical command runbooks.
4. Keep canonical edits in `.claude/agents/`, `.agents/skills/`, and `.claude/commands/`.

This adapter is intentionally thin. It gives Codex a stable place to discover the design team while keeping the existing Claude/OpenCode harness intact.
